# Scripting — One Message, Structure, Psychology

The script is decided before a single frame is designed. Motion amplifies a message; it cannot create one.

## 1. The one message

Answer in `scripts/01-one-message.md` before anything else:

```markdown
**One message:** Get fully booked in 7 days without running ads.
**Audience:** Solo service businesses, 1–5 staff, tired of empty calendars.
**Platform / format:** Instagram Reels, 1080×1920, 30 fps, 30 s, sound-off first.
**The one CTA:** "Book your free setup call."
**Proof we can show:** Calendar filling up in the real UI; 3 customer numbers.
```

- One problem, one turn, one outcome. If it needs "and", it is two videos.
- **Weak:** *"We help businesses grow with smart tools."* **Strong:** *"Get fully booked in 7 days without ads."* Specific, outcome-led, believable.
- If you cannot write it, **stop and ask the developer.** That question is the most valuable one in the whole project.

## 2. Pick the structure for the format

Timings are for a 30–45 s piece; scale them proportionally.

**Direct-response ad (problem → solution)**

| Beat | Time | Job |
|---|---|---|
| Hook | 0–3 s | Pattern interrupt; a bold claim or a pain the viewer feels right now |
| Problem | 3–8 s | Start in the middle of it — no easing in |
| Agitation | 8–15 s | Make it worse; the cost of doing nothing |
| Turn | 15–18 s | "Then this changed." The release starts |
| Proof / demo | 18–38 s | Show the UI, the result, the before/after — don't tell |
| CTA | 38–45 s | One directive. "Start your free trial", never "Learn more" |

**Product launch / reveal (anticipation → reveal → features → availability)**
Tease (a detail, a silhouette, a sound) → the reveal (the signature moment) → 3 features max, one per beat, each shown → price/date/where → logo lock-up. Momentum over information.

**Explainer (question → model → payoff)**
The question the viewer has → the simplest mental model (one diagram that builds) → the steps, each a visual change → what they get → CTA. Slower cuts; let diagrams breathe.

**Logo sting / brand intro (2–6 s)**
One idea expressed in motion — assemble, reveal, transform. Hit the logo lock-up on a strong audio accent and hold it ≥ 1 s.

**Social loop (6–15 s)**
The last frame flows into the first. Hook and payoff are the same visual. Text readable in one glance.

**Data story / stat video**
One number per beat, counted up, with context ("3× faster *than last year*"). Never two charts on screen at once.

Add beats as needed — social proof, objection handling, urgency — but every added beat costs seconds from somewhere.

## 3. Script principles

- **Hook in 1.5–3 s.** People decide instantly. A pattern interrupt, a bold statement, a relatable pain, a visual that should not be possible.
- **Start in the middle.** Drop the viewer into something already happening.
- **Tension → release.** Build discomfort (problem, confusion, cost), then release it (solution, clarity, relief). The turn is the most important cut.
- **Tight beats tight.** Fast at the start, slower when explaining, accelerate into the CTA.
- **Show, don't tell.** Selling software? Show the UI doing the thing. Selling a result? Show the result.
- **Sound-off first** for social: the story must read with captions and on-screen copy alone.
- **One CTA, concrete.** A verb and an outcome.

## 4. Writing on-screen copy

- 3–7 words per card. If it needs a sentence, it needs two cards.
- Reading time ≈ `0.3 s + 0.25 s per word`, minimum 1 s on screen.
- Front-load the important word: "**7 days.** Fully booked."
- Numbers beat adjectives: "3× faster" over "much faster".
- Write the script as a table so scene direction can lift it directly:

```markdown
| # | Time | On screen | VO / caption | Audio |
|---|---|---|---|---|
| 1 | 0.0–2.5 s | "Empty calendar again?" | — | low drone, hit at 0.4 s |
| 2 | 2.5–6.0 s | Calendar UI, days greying out | "Another week of no-shows." | ticking |
```

## 5. Persuasion psychology layer

`scripts/03-psychology.md` names the models applied, *where*, and *why*. Pick the few that fit — never all.

| Beat | Models |
|---|---|
| Hook | Pattern interrupt, curiosity gap / Zeigarnik (open a loop), availability heuristic (make it vivid) |
| Problem / agitation | Loss aversion (losses weigh ~2× gains), status quo cost, specificity |
| Turn / solution | Contrast effect, anchoring (before → after), simplicity |
| Proof | Social proof, authority, concrete numbers, demonstration |
| CTA | Low-friction first step (foot-in-the-door), immediate benefit, honest urgency or scarcity |
| Pricing | Anchoring, charm pricing, rule of 100 (% under $100, absolute over) |

Never fake urgency, fabricate numbers, or invent testimonials — if the proof doesn't exist, the script uses a demo instead.

## 6. Fixing an existing script

1. Watch it in Studio as a viewer: where would you scroll away? Note the second.
2. Write what the current one message actually is (often: none, or three).
3. Keep what works — a strong shot, a line that lands.
4. Propose the smallest re-script that fixes the drop-off point, then the larger one if warranted, with the trade-off.
